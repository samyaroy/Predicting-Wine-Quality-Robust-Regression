# Wine Quality Dataset Description

- **y**: Quality rating (maximum of 20)

## Features:
- **x_1**: Wine varietal  
  - 0 = Cabernet Sauvignon  
  - 1 = Shiraz
- **x_2**: pH
- **x_3**: Total SO₂ (ppm)
- **x_4**: Color density
- **x_5**: Wine color
- **x_6**: Polymeric pigment color
- **x_7**: Anthocyanin color
- **x_8**: Total anthocyanins (g/L)
- **x_9**: Degree of ionization of anthocyanins (percent)
- **x_10**: Ionized anthocyanins (percent)
